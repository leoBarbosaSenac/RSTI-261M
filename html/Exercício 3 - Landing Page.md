# Exercício — Landing Page de um Escritório de Advocacia

## Objetivo

Neste exercício, você deverá desenvolver uma **Landing Page** para um escritório de advocacia utilizando **HTML** e **CSS**.

O foco da atividade é colocar em prática os conceitos estudados até o momento, principalmente a construção de layouts utilizando **Flexbox**.

---

# Antes de Começar

Uma Landing Page é uma página criada para apresentar uma empresa, produto ou serviço de forma clara e objetiva.

Antes de iniciar a programação, pense em como a página será dividida em seções e como cada elemento será organizado utilizando Flexbox.

---

# Pesquisar faz parte do desenvolvimento

O CSS é uma linguagem muito ampla e existem centenas de propriedades diferentes.

Durante a atividade, sinta-se à vontade para pesquisar propriedades que possam ajudar na construção da interface, desde que estejam relacionadas ao conteúdo estudado.

Pesquisar documentação e exemplos faz parte da rotina de qualquer desenvolvedor.

---

# Tema

Desenvolva a Landing Page de um **escritório de advocacia** fictício.

Você pode criar livremente:

- Nome do escritório;
- Logotipo (texto ou imagem);
- Áreas de atuação;
- Equipe;
- Informações de contato;
- Endereço;
- Textos e imagens ilustrativas.

---

# Estrutura Obrigatória

A página deverá conter, no mínimo:

## Header

- Nome ou logotipo;
- Menu de navegação (`<nav>`);
- Pelo menos **4 opções** no menu.

Exemplo:

- Início
- Sobre
- Serviços
- Contato

---

## Hero Section

Uma seção principal contendo:

- Título de destaque;
- Texto de apresentação;
- Um botão;
- Imagem ilustrativa (opcional).

---

## Pelo menos mais 3 Sections

Exemplos:

- Sobre o escritório;
- Áreas de atuação;
- Equipe;
- Diferenciais;
- Contato.

---

## Cards

A página deverá conter **pelo menos 3 cards**.

Eles podem representar:

- Serviços;
- Áreas de atuação;
- Advogados;
- Diferenciais.

Cada card deve possuir:

- Título;
- Pequena descrição;
- Ícone ou imagem (opcional).

---

## Footer

O rodapé deverá conter informações como:

- Nome do escritório;
- Telefone;
- E-mail;
- Endereço.

---

# Requisitos Técnicos

Utilize obrigatoriamente:

- HTML semântico;
- CSS externo;
- Flexbox para organizar o layout.

Durante o desenvolvimento, procure aplicar os conceitos vistos em aula:

- Seletores;
- Classes e IDs;
- Cores;
- Tipografia;
- Background;
- Box Model;
- Display;
- Position (quando necessário);
- Flexbox;
- Margin e Padding;
- Alinhamento de elementos.

---

# Estrutura HTML Sugerida

Você pode utilizar elementos como:

- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<footer>`
- `<div>`
- `<button>`
- `<img>`
- `<h1>` até `<h6>`
- `<p>`

---

# Dicas

- Escolha uma paleta de cores que transmita profissionalismo.
- Utilize uma tipografia legível.
- Mantenha um bom espaçamento entre os elementos.
- Organize o HTML utilizando classes com nomes claros.
- Utilize o Flexbox para alinhar os elementos da página.
- Mantenha o código bem indentado e organizado.

---

# Estrutura de Arquivos

```text
escritorio-advocacia/
│
├── index.html
├── style.css
└── img/
```

Caso utilize imagens, organize-as dentro da pasta `img`.

---

# Desafio ⭐

Tente construir toda a página utilizando **apenas Flexbox** para organizar os elementos.

O objetivo é praticar ao máximo essa ferramenta antes de conhecer outras formas de criar layouts.
