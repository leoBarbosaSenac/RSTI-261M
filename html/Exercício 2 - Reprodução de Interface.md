# Exercício — Reproduzindo uma Interface Real com HTML e CSS

## Objetivo

Neste exercício, você deverá reproduzir a interface da tela de login do **Spotify** utilizando **apenas HTML e CSS**.

<img width="1918" height="941" alt="image" src="https://github.com/user-attachments/assets/454e81b3-c57a-479e-9a87-813ddf443740" />


O objetivo é colocar em prática os conceitos estudados até o momento, desenvolvendo uma interface o mais fiel possível ao modelo fornecido.

> **Importante:** Não é necessário implementar nenhuma funcionalidade. O foco deste exercício é exclusivamente a construção da interface.

---

# Antes de Começar

No desenvolvimento Front-End, é muito comum receber um layout pronto, criado por um designer, e reproduzi-lo utilizando HTML e CSS.

Neste exercício, esse será exatamente o desafio.

Observe atentamente detalhes como:

- Espaçamentos;
- Alinhamentos;
- Tamanhos;
- Cores;
- Tipografia;
- Bordas;
- Cantos arredondados;
- Organização dos elementos.

Quanto mais fiel a reprodução ficar, melhor será o resultado.

---

# Pesquisar faz parte do desenvolvimento

Nem todas as propriedades necessárias para reproduzir a interface foram apresentadas em aula.

Isso é completamente normal.

Caso seja necessário, pesquise na internet sobre novas propriedades de CSS para melhorar sua página.

Alguns exemplos de propriedades que podem ser úteis:

- `border-radius`
- `cursor`
- `:hover`
- `font-family`
- `box-shadow`
- `outline`
- `transition`
- `letter-spacing`

Aprender a pesquisar documentação, exemplos e soluções faz parte da rotina de qualquer desenvolvedor.

# Modelo

Utilize a imagem disponibilizada como referência e tente reproduzi-la da forma mais fiel possível.

---

# Paleta de Cores

Como referência, utilize as principais cores presentes na interface.

| Elemento | Cor |
|----------|---------|
| Fundo | `#121212` |
| Botão principal | `#1ED760` |
| Texto principal | `#FFFFFF` |
| Texto secundário | `#B3B3B3` |
| Bordas dos botões | `#727272` |
| Campo de texto | `#121212` |
| Borda do campo | `#535353` |

> Pequenas diferenças de tonalidade são aceitáveis.

---

# Requisitos

A página deverá conter, no mínimo:

- Logo do Spotify;
- Título principal;
- Campo de e-mail;
- Botão verde **"Continuar"**;
- Texto separador **"ou"**;
- Botões de login alternativo;
- Links inferiores;
- Texto de rodapé.

---

# Estrutura HTML

Procure utilizar uma estrutura organizada e semântica.

Sugestão de elementos:

- `<main>`
- `<div>`
- `<form>`
- `<label>`
- `<input>`
- `<button>`
- `<a>`
- `<img>`
- `<p>`

Não é obrigatório utilizar todos eles, mas eles podem facilitar a organização da interface.

---

# CSS

Durante a construção da interface, procure utilizar os conceitos estudados até o momento:

- Seletores;
- Classes e IDs;
- Cores;
- Background;
- Box Model;
- Display;
- Position (quando necessário);
- Flexbox;
- Bordas;
- Espaçamentos (`margin` e `padding`);
- Tipografia.

---

# Desafio ⭐

Pesquise e utilize pelo menos **duas propriedades de CSS** que ainda não foram apresentadas em aula.

Algumas sugestões:

- `border-radius`
- `transition`
- `cursor`
- `box-shadow`
- `opacity`
- `letter-spacing`
- `filter`
- `transform`

---

# Dica

Antes de começar a escrever o código, observe a interface por alguns minutos e tente identificar como ela pode ser dividida em blocos (`<div>`), seções e grupos de elementos.

Uma boa prática é fazer um pequeno esboço da estrutura antes de iniciar a programação. Planejar a interface primeiro torna o desenvolvimento mais simples, organizado e facilita futuras alterações.
